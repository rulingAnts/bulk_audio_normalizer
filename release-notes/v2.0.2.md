## What changed

- **File names should no longer stop the batch.** In v2.0.1, a file such as `07 Johnny Don't Go.wav` (with an apostrophe) stopped the whole batch. Version 2.0.2 should now handle that name and every other character Windows allows in a file name. That includes accented letters and umlauts (ö ü ä Ö Ü Ä), ß, €, @, #, +, ~, ², ³, !, &, %, commas, spaces and names with several dots, such as `a.b.c.wav`. The preview window handles the same names.
- **No more false "Completed".** If a batch stops on an error, it now shows the error instead of "Completed".
- **Files that cannot be processed are listed.** If a file cannot be processed (for example, it is damaged or not really a WAV file), the batch goes on with the other files. That file is marked red, and at the end the app lists the files it could not write. Before, it said "Completed" and the files were simply missing.
- Files ending in `.wave` (not only `.wav`) are now written.
- Files in subfolders are listed with their folder (for example `Disc 1\01.wav`), so two files with the same name in different subfolders each get their own line in the progress list.
- The hidden `._` files a Mac leaves on USB drives and memory cards are skipped. They are not recordings.

Before each build, automatic tests now run a real batch on Windows with files named with all of these characters.

## Download

- **Windows (64-bit):** download **Bulk.Audio.Normalizer.exe** below. It is portable: there is no installer, so just double-click it. If Windows SmartScreen warns you, choose "More info" → "Run anyway".
- **macOS (Apple silicon, M1 or newer; macOS 11 or later):** download **Bulk.Audio.Normalizer.dmg** below, open it and drag the app to Applications. The first time you open the app, macOS says it cannot check it, because it is not signed with an Apple developer certificate. Open System Settings → Privacy & Security, scroll down and click "Open Anyway". There is no build for Intel Macs yet.

## FFmpeg in the macOS app

The macOS app comes with FFmpeg 6.1.6, which we built from FFmpeg's own source for this release. This software uses code of FFmpeg licensed under the LGPLv2.1, and its source can be downloaded here: **ffmpeg-6.1.6-source.tar.xz** below. It is unmodified; `BUILD-INFO.txt` inside it gives the exact configure line. The license text and a notice are also inside the app.

The macOS downloads of v1.5.1, v2.0.0 and v2.0.1 have been removed. The FFmpeg inside them was a build that we may not pass on. If you installed one of them, it keeps working, but please use this version from now on.
